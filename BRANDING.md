# GoreeCloud Router OS — Branding

- Official product name: **GoreeCloud Router OS**.
- Repository name: `goreecloud-router-os`.
- Product-facing interfaces must use the official product name unless a verified GoreeCloud naming rule requires a shorter contextual label.
- The visual administration experience is planned to use Glaze UI. Current repository source contains no accepted production Glaze UI implementation.
- Do not reuse OPNsense, OpenWrt, GL.iNet, Firewalla, or other third-party logos, trademarks, trade dress, or branded artwork as GoreeCloud product assets.
- Do not imply certification, endorsement, compatibility, or partnership that has not been verified.
- Approved GoreeCloud logos, icons, typography, and design assets must come from the authoritative GoreeCloud branding sources applicable at the time of implementation.
