# GoreeCloud Router OS — Competitive Objectives

GoreeCloud Router OS uses mature products as design references without cloning their code or product identity.

## Reference strengths

- OPNsense: deep firewalling, routing, and advanced administration.
- OpenWrt: Linux hardware flexibility and networking extensibility.
- GL.iNet: approachable travel-router and VPN workflows.
- Firewalla: understandable device-centric visibility and protective workflows.

## GoreeCloud differentiation objectives

- Own the configuration/state engine and management architecture.
- Treat safe apply, verification, rollback, and evidence as core behavior rather than secondary tooling.
- Preserve explicit authority boundaries across the GoreeCloud platform.
- Make privacy minimization and retention controls structural requirements.
- Avoid claiming network protection that runtime evidence cannot support.
- Deliver a Glaze UI administration experience only after applicable conformance can be verified.

These are objectives, not claims that the current prototype already meets competitor feature breadth or production quality.
